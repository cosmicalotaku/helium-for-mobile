## 1. Project Mission & Context

The goal of this project is to port the desktop experience of the **Helium Browser** (`imputnet/helium`) to Android:
- **Zero Noise & Zero Unsolicited Requests:** No Google account sign-in prompts, Discover feeds, promotional notifications, or AI upsells.
- **First-Class Extension Support:** Install directly from the Chrome Web Store without switching to desktop mode, local `.crx`/`.zip` sideloading, and SAF unpacked extension loading.
- **Manifest V2 (MV2) Preserved:** Full uncompromised support for the MV2 extension API (`webRequestBlocking`) to run full uBlock Origin.
- **Built-in uBlock Origin:** Pre-installed component extension operating out-of-the-box on first launch.
- **Minimalist Chrome & Helium Feel:** Compact toolbar, user-customizable toolbar button layout, clean New Tab Page, and AMOLED / Material You custom theming.

## 3. Key Decisions Recorded (Architecture Decision Records)

1. [**ADR-01: Base Selection**](../docs/ADR/ADR-01-base-selection.md)
   - Adopted **Option A**: Use GrapheneOS's **Vanadium** as the submodule base, adopt **Titanium's** extension runtime and MV2 patches, and build custom Helium privacy/UI layers on top.
2. [**ADR-02: App Name, Package ID, & Branding**](../docs/ADR/ADR-02-branding-and-identity.md)
   - App Name: **Aether Browser** (slug `aether`).
   - Android Package ID: `app.aether.browser`.
   - Themed icon: Geometric stylized shield vector in `res/drawable/themed_app_icon.xml`.
3. [**ADR-03: Filter-List & Extension Update Network Paths**](../docs/ADR/ADR-03-network-paths.md)
   - Decentralized direct downloads with strict header anonymization (strip user identifiers, `X-Client-Data`, Omaha client IDs).
   - User master toggle provided in **Settings > Aether Services**.
4. [**docs/LICENSES.md**](../docs/LICENSES.md)
   - Resolved GPL-2.0-only (Vanadium) vs GPL-3.0 (Helium / uBO): All Helium UI features are cleanly re-implemented in Android Java/XML under GPL-2.0; uBO is distributed via extension runtime as mere aggregation.
