## 1. Project Mission & Context

Aether Browser brings the clean, minimalist, user-controlled desktop experience of the **Helium Browser** (`imputnet/helium`) to Android:
- **Zero Noise & Zero Unsolicited Requests:** No Google account sign-in prompts, Discover feeds, promotional notifications, or AI upsells.
- **First-Class Extension Support:** Install directly from the Chrome Web Store without switching to desktop mode, local `.crx`/`.zip` sideloading, and SAF unpacked extension loading.
- **Manifest V2 (MV2) Preserved:** Full uncompromised support for the MV2 extension API (`webRequestBlocking`) to run full uBlock Origin.
- **Built-in uBlock Origin:** Pre-installed component extension operating out-of-the-box on first launch.
- **Authentic Helium Feel:** Compact 48dp toolbar, customizable button layout, clean New Tab Page, Pure Black AMOLED theming (`#000000`), and flat Aether Services settings.

### 3.2 Five Production Patches Integrated into `patches/series`
1. [`patches/aether/ui/0015-compact-and-customizable-toolbar.patch`](../patches/aether/ui/0015-compact-and-customizable-toolbar.patch):
   - Reduced `toolbar_height_no_shadow` to `48dp`, `toolbar_button_width` to `40dp`, and `toolbar_url_bar_min_height` to `36dp`.
   - Injected `share_button` and `new_tab_button` into `toolbar_phone.xml`.
   - Implemented dynamic `updateCustomToolbarButtons()` in `ToolbarPhone.java`.
   - Created `ToolbarCustomizationSettings.java` and `toolbar_customization_preferences.xml`.
2. [`patches/aether/ui/0016-clean-overflow-and-context-menus.patch`](../patches/aether/ui/0016-clean-overflow-and-context-menus.patch):
   - Suppressed Google sign-in promo cards and `help_id` from `main_menu.xml` and `AppMenuPropertiesDelegateImpl.java`.
   - Added direct "Copy link" menu item.
   - Simplified long-press context menus in `ChromeContextMenuPopulator.java` by removing tab-group and reading-list clutter.
3. [`patches/aether/ui/0017-minimalist-clean-new-tab-page.patch`](../patches/aether/ui/0017-minimalist-clean-new-tab-page.patch):
   - Suppressed Google Discover feed in `FeedSurfaceCoordinator.java` (`isFeedExpanded() -> false`, `isFeedEnabled() -> false`).
   - Removed `ExploreSites` container and added user toggle for shortcut tiles in `NewTabPageLayout.java`.
4. [`patches/aether/ui/0018-amoled-pure-black-and-accent-theming.patch`](../patches/aether/ui/0018-amoled-pure-black-and-accent-theming.patch):
   - Added "Pure Black (AMOLED)" option to `ThemeSettingsFragment.java`.
   - Mapped true `#000000` black toolbar and window background in `ThemeUtils.java`.
   - Defined color tokens for Helium Amber (`#F59E0B`), Cyan (`#06B6D4`), Violet (`#8B5CF6`), and Emerald (`#10B981`) in `values-night/colors.xml`.
5. [`patches/aether/settings/0019-aether-services-and-flat-settings.patch`](../patches/aether/settings/0019-aether-services-and-flat-settings.patch):
   - Added "Aether Services" at the top of `main_preferences.xml`.
   - Created `AetherServicesSettings.java` and `aether_services_preferences.xml` with transparent user toggles for ad blocking, filter list updates, extension updates, search suggestions, and network prefetching.
