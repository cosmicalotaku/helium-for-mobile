## 1. Project Mission & Context

Aether Browser ports the desktop experience of the **Helium Browser** (`imputnet/helium`) to Android:
- **Zero Noise & Zero Unsolicited Requests:** No Google account sign-in prompts, Discover feeds, promotional notifications, or AI upsells.
- **First-Class Extension Support:** Install directly from the Chrome Web Store without switching to desktop mode, local `.crx`/`.zip` sideloading, and SAF unpacked extension loading.
- **Manifest V2 (MV2) Preserved:** Full uncompromised support for the MV2 extension API (`webRequestBlocking`) to run full uBlock Origin.
- **Built-in uBlock Origin:** Pre-installed component extension operating out-of-the-box on first launch.
- **Minimalist Chrome & Helium Feel:** Compact toolbar, user-customizable toolbar button layout, clean New Tab Page, and AMOLED / Material You custom theming.

## 6. Hard Rules & Guidelines

- **R-NO-INVENT:** Never guess Chromium class names, GN args, or prefs. Always locate them in real source files or base project scripts.
- **R-SMALL:** Keep patch diffs minimal and targeted to maximize rebase stability.
- **Patch Format:** All patches must be unified diffs in `patches/aether/<area>/<short-name>.patch` and listed in `patches/series`.
- **One Task Card at a Time:** Produce plan -> patch -> verification -> update `docs/STATUS.md`.
